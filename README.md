# Pulsar Launcher

Launcher para Minecraft: Java Edition con cliente integrado, actualizaciones automáticas y verificación de identidad para networks.

En este repositorio encontrarás todas las versiones publicadas: instaladores para Windows, Linux y macOS, los árboles de actualización incremental y el plugin del Legit Module para servidores Paper/Spigot/Velocity.

- Descarga: https://pulsarlauncher.com
- Todas las versiones: https://github.com/metrofico/pulsar-releases/releases
